# 医学影像分割软件

## 系统说明

这是一个基于 PyQt5 的医学影像分割软件，支持 DICOM、NIfTI、NRRD 等格式的医学影像加载、可视化、标注和分割。软件集成了传统分割算法和深度学习模型，提供多种血管分割方案。

## 系统要求

- Python 3.11 或更高版本
- Windows 操作系统（推荐 Windows 10/11）
- 至少 8GB 内存（推荐 16GB 或更多）
- 支持 CUDA 的显卡（可选，用于加速深度学习模型）

## 安装步骤

### 1. 安装 Python 依赖

在 `our_snap` 文件夹下打开命令行，执行：

```bash
pip install -r requirements.txt
```

或者如果使用虚拟环境：

```bash
# 创建虚拟环境（可选）
python -m venv .venv

# 激活虚拟环境
# Windows:
.venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt
```

### 2. 运行程序

```bash
python main.py
```

## 功能特性

### 核心功能
- **多格式支持**：支持 DICOM、NIfTI、NRRD 等医学影像格式
- **四视图可视化**：轴向、冠状、矢状三个正交视图 + 3D 渲染视图
- **手动标注**：支持画笔、橡皮擦、指针、缩放、平移等工具
- **标签管理**：支持多标签创建、编辑、删除、颜色设置
- **撤销/重做**：支持标注操作的撤销和重做

### 分割功能
- **传统分割方法**：
  - 基于阈值分割
  - 基于边缘分割（Canny 边缘检测）
  - 基于区域生长分割
- **AI 自动分割**：
  - 支持 MobileUViT 深度学习模型
  - 模型变体选择：mobileuvit（小型模型 - 高速度）、mobileuvit_l（大型模型 - 高精度）
  - 血管分解方法：adaptive、fixed_1.0/1.5/2.0/2.5、median、percentile_25/50/75
- **主动轮廓分割**：基于主动轮廓算法的半自动分割

### 图像处理
- **窗宽窗位调整**：支持自定义灰度范围
- **图像测量**：距离测量、面积测量、体积测量
- **十字准线**：三视图同步定位
- **切割平面**：支持在3D视图中添加切割平面，帮助医生进行手术规划
- **3D可视化优化**：通过点云降采样和渲染优化，提高3D血管树的显示流畅度

### 数据管理
- **数据库管理**：支持 522 数据库格式的序列管理和加载
- **Excel 信息查看**：支持查看患者对应的 Excel 表格信息
- **标签保存/加载**：支持标签的保存和加载（NIfTI 格式）
- **PDF报告生成**：一键导出包含图文数据与风险评估的PDF手术规划报告

## 使用说明

### 加载影像

1. **从文件加载**：点击 "Load Image" 按钮，选择单个影像文件（.nii.gz, .nrrd, .dcm）
2. **从文件夹加载**：点击 "Load DICOM Folder" 按钮，选择 DICOM 序列文件夹
3. **从数据库加载**：点击 "Open DB Dialog" 按钮，连接数据库并选择序列

### 标注操作

1. **选择工具**：在工具栏选择指针、缩放、平移、画笔或橡皮擦工具
2. **设置画笔大小**：调整 Brush Size 滑块
3. **添加标签**：在 Segmentation Labels 区域点击 "+" 按钮添加新标签
4. **绘制标注**：使用画笔工具在图像上绘制标注
5. **擦除标注**：使用橡皮擦工具擦除标注
6. **调整透明度**：使用 Overall Label Opacity 滑块调整标签显示透明度

### 分割功能

#### AI 自动分割
1. 点击 "AI Segment" 按钮
2. 选择模型变体：
   - mobileuvit_l (大型模型 - 高精度)：精度更高，速度较慢
   - mobileuvit (小型模型 - 高速度)：速度更快，精度略低
3. 选择血管分解方法：
   - percentile_50 (推荐)：使用 50% 百分位数作为阈值
   - adaptive：自适应阈值，适合不同图像
   - fixed_1.0/1.5/2.0/2.5：固定阈值
   - median：中位数阈值
   - percentile_25/75：不同百分位数阈值
4. 点击 "开始分割" 执行分割

#### 传统分割方法
1. 点击 "AI Segment" 按钮
2. 选择传统分割方法：
   - 基于阈值分割：使用自适应阈值进行分割
   - 基于边缘分割：使用 Canny 边缘检测
   - 基于区域生长分割：基于种子点的区域生长算法

#### 主动轮廓分割
1. 添加种子点（点击 "Toggle Seed Mode" 按钮）
2. 点击 "Active Contour" 按钮执行分割

### 标签管理

1. **添加标签**：点击 "+" 按钮，输入标签名称
2. **删除标签**：点击标签右侧的 "×" 按钮
3. **选择标签**：点击标签名称选中当前活动标签
4. **设置颜色**：标签会自动分配颜色，也可手动调整
5. **保存标签**：点击 "Save Label" 按钮保存为 NIfTI 文件
6. **加载标签**：点击 "Load Label" 按钮加载已保存的标签
7. **清除标签**：点击 "Clear Label" 按钮清除所有标签

### 图像处理

1. **调整窗宽窗位**：拖动窗宽窗位滑块
2. **重置视图**：点击 "Reset" 按钮恢复默认视图
3. **测量距离**：点击 "Measure Distance" 按钮，在图像上点击两点测量距离
4. **更新 3D 视图**：点击 "Update 3D View" 按钮刷新 3D 渲染
5. **切割平面**：
   - 点击 "添加切割平面" 按钮
   - 点击 "显示3D血管树" 按钮查看3D视图
   - 在3D视图中，切割平面会以青色半透明形式显示，帮助医生进行手术规划

### PDF报告生成

1. **准备数据**：确保已加载影像并进行分割
2. **点击生成报告**：点击 "生成PDF报告" 按钮
3. **选择保存路径**：在弹出的对话框中选择PDF报告的保存路径
4. **查看报告**：报告生成完成后，会自动打开保存路径，查看生成的PDF报告

## 注意事项

1. **模型文件**：
   - AI 模型文件（best_model.pth）需要放在 model 文件夹中
   - 支持 PyTorch 模型（.pth）和 ONNX 模型（.onnx）
   - 小型模型（mobileuvit）和大型模型（mobileuvit_l）共享同一个权重文件

2. **数据库路径**：
   - 数据库路径需要在程序中手动选择
   - 支持 522 数据库格式

3. **Excel 文件**：
   - Excel 文件需要放在数据库根目录下（与 data 文件夹同级）

4. **系统路径**：
   - 所有路径都是相对路径或用户选择，没有硬编码路径

5. **内存要求**：
   - 处理大型医学影像需要足够的内存
   - 建议关闭其他占用内存的程序

## 常见问题

### Q: 程序无法启动？
A: 检查是否已安装所有依赖：`pip install -r requirements.txt`

### Q: 无法加载 DICOM 文件？
A: 确保 DICOM 文件完整，且目录结构正确（如 SE*/IM* 格式）

### Q: 数据库连接失败？
A: 确保选择的路径是数据库根目录（通常包含 data 文件夹）

### Q: AI 分割失败？
A: 
- 检查模型文件是否存在（model/best_model.pth）
- 检查 PyTorch 是否正确安装
- 查看控制台输出的错误信息

### Q: 模型加载失败？
A:
- 确保模型文件格式正确（.pth 或 .onnx）
- 检查 PyTorch 版本兼容性
- 小型模型（mobileuvit）需要智能权重加载，部分权重会被跳过

### Q: 分割结果不理想？
A:
- 尝试不同的血管分解方法
- 调整模型变体（大型模型精度更高）
- 检查输入图像质量
