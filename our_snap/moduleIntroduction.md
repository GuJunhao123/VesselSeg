# 医学影像分割软件 - 模块介绍

## 项目概述

本项目是一个基于PyQt5开发的医学影像分割软件，主要功能包括：
- 医学影像的加载、显示和管理
- 三视图（轴位、矢状位、冠状位）可视化
- 手动标注和编辑
- 主动轮廓分割算法
- AI自动分割
- 病例归档和历史记录管理

## 项目结构

## 模块详细介绍

### 1. 主程序入口 (main.py)

**功能**: 程序的启动入口，负责初始化应用程序和主窗口

**主要内容**:
- 设置高DPI支持（AA_EnableHighDpiScaling和AA_UseHighDpiPixmaps）
- 创建QApplication实例
- 创建并显示MainWindow主窗口
- 运行事件循环

**关键代码**:
```python
QApplication.setAttribute(Qt.AA_EnableHighDpiScaling, True)
QApplication.setAttribute(Qt.AA_UseHighDpiPixmaps, True)
```

### 2. 主界面布局 (ui_layout.py)

**功能**: 实现软件的主界面布局，包括左侧工具栏、中间2×2视图区和右侧参数设置区

**主要组件**:
- **左侧工具栏**:
  - Main Toolbar: 指针、缩放、平移、画笔、橡皮擦等工具
  - Cursor Inspector: 显示光标位置和强度信息
  - Patient Info: 显示病人信息
  - Segmentation Labels: 标签管理
  - 3D操作: 3D视图更新、种子点添加、分割操作
  - 数据库对接: 打开数据库对话框
  - 病例归档: 保存病例到库、搜索历史病例

- **中间视图区**:
  - 2×2布局的切片视图（轴位、矢状位、冠状位、3D预览）
  - 十字线联动
  - 方向标识

- **右侧参数设置区**:
  - 分割算法参数（迭代次数、平滑度、扩张力等）

**核心功能**:
- 影像和标签的加载、保存
- 手动标注（画笔和橡皮擦工具）
- 种子点添加和3D分割
- AI自动分割
- 病例归档和历史记录管理

### 3. 影像读写模块 (image_io.py)

**功能**: 支持多种医学影像格式的读取和保存，保留空间参数

**支持的格式**:
- NIfTI (.nii, .nii.gz)
- DICOM (单个文件或序列文件夹)
- NRRD (.nrrd, .nhdr)

**核心方法**:
- `load_image()`: 加载医学影像文件
- `save_image()`: 保存医学影像文件
- `load_label_map()`: 加载标签掩码文件
- `save_label_map()`: 保存标签掩码文件

**特点**:
- 自动识别文件格式
- 支持无扩展名的DICOM文件
- 保留空间参数（spacing、origin、direction）
- 提取DICOM元信息

### 4. 可视化模块 (visualization.py)

**功能**: 实现医学影像的可视化，包括2×2布局视图、十字线联动、方向标识等

**主要组件**:
- `SliceViewer`: 单个切片视图，支持轴位、矢状位、冠状位
- `FourViewWidget`: 2×2布局的四视图组件

**核心功能**:
- 切片显示和切换
- 十字线联动
- 方向标识（前、后、左、右、上、下）
- 缩放和平移
- 窗宽窗位调整
- 标签叠加显示
- 画笔和橡皮擦工具
- 缩放条显示

**特点**:
- 保持物理比例显示
- 支持物理坐标
- 实时同步拖拽
- 响应式布局

### 5. 分割算法模块 (segmentation.py)

**功能**: 实现主动轮廓（Snake）分割算法

**算法类型**:
- **Region Competition**: 基于区域竞争的主动轮廓算法
- **Edge-Based**: 基于边缘检测的主动轮廓算法

**核心方法**:
- `set_image()`: 设置图像数据
- `set_seed_points()`: 设置种子点
- `region_competition()`: 执行区域竞争分割
- `edge_based()`: 执行边缘基于分割

**参数设置**:
- 迭代次数
- 平滑度
- 扩张力（Region Competition）
- 边缘权重（Edge-Based）

### 6. AI自动分割接口 (ai_interface.py)

**功能**: 支持ONNX模型和PyTorch模型推理，实现AI自动分割

**支持的模型格式**:
- ONNX (.onnx)
- PyTorch (.pth, .pt)

**核心方法**:
- `load_model()`: 加载AI模型
- `preprocess_image()`: 预处理图像数据
- `postprocess_mask()`: 后处理模型输出
- `segment()`: 执行AI分割

**特点**:
- 支持GPU加速
- 与pre4.py模型推理脚本集成
- 自动预处理和后处理
- 滑窗推理支持

### 7. 数据库管理模块 (database.py)

**功能**: 实现病例归档和历史记录管理

**核心方法**:
- `save_record()`: 保存病例记录
- `get_patient_history()`: 查询病人历史记录
- `get_all_records()`: 获取所有记录

**存储方式**:
- 使用JSON格式存储日志文件
- 按病人编号组织存储目录
- 保存原始影像和分割结果

**特点**:
- 支持DICOM序列和单个文件
- 自动处理文件复制和重命名
- 支持关键词搜索
- 按时间倒序排列记录

## 使用流程

1. **加载影像**: 通过"Load Image"或"Load DICOM Folder"按钮加载医学影像
2. **查看影像**: 使用鼠标滚轮切换切片，拖拽平移，右键缩放
3. **手动标注**: 选择画笔工具，设置画笔大小，在视图中绘制标注
4. **自动分割**: 
   - 方法1: 添加种子点，选择分割算法参数，点击"Segment 3D"
   - 方法2: 点击"AI自动分割"按钮，使用AI模型进行自动分割
5. **保存结果**: 点击"Save Label"按钮保存分割结果
6. **归档病例**: 点击"保存病例到库"按钮，将当前影像和分割结果归档
7. **查询历史**: 点击"搜索历史病例"按钮，查询和加载历史病例
