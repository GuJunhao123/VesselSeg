# 🧠 Medical AI Segmentation Platform

> 基于深度学习的医学图像分割与可视化分析平台，集成 AI 模型推理、3D 可视化、量化分析与报告生成等核心功能。

---

## 📦 项目搭建指南

### 1. 环境准备

| 步骤 | 操作 | 说明 |
| :---: | :--- | :--- |
| 1️⃣ | **配置 Conda 环境** | 使用国内镜像源下载 PyTorch 及相关依赖库 |
| 2️⃣ | **安装 CUDA** | 启用 GPU 加速，大幅提升 AI 推理性能 |
| 3️⃣ | **安装 Git LFS** | 管理大文件（`.nii`, `.pth`），确保拉取完整项目 |

> [!IMPORTANT]
> **关于大文件管理**
> GitHub 仅保留 `.nii` 等大文件的 **LFS 指针**，实际二进制文件存储在仓库之外。
> 克隆或拉取项目前，请务必先安装 [Git LFS](https://git-lfs.github.com/)，否则无法获取完整的影像数据与模型权重。

### 2. Model 运行流程

1.  下载 Conda，配置环境，使用镜像下载 PyTorch 和相关库
2.  配置文件路径、权重文件路径及 CT 输入文件路径
3.  修改 `pred4` 中的路径代码
4.  ✅ 运行 `pred4`，生成预测图片和 `.nii` 结果文件（无需对比图片）

### 3. 软件运行流程

1.  安装软件所需依赖库，完成初步运行验证
2.  将数据库存储方式改为 Log 日志保存
3.  添加对 PyTorch 模型的调用支持
